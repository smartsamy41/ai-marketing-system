# Methodik

Free Basics verwendet eine quellenbasierte redaktionelle Methodik.

## Grundprinzipien

- keine erfundenen Produktdaten
- keine erfundenen Preise
- keine erfundenen Bewertungen
- keine erfundenen Tests
- keine unbelegten Garantien
- überprüfbare Quellen
- transparente Affiliate-Kennzeichnung
- regelmäßige Qualitätsprüfung

## Datenquellen

Produkt- und Angebotsinformationen werden aus verfügbaren und überprüfbaren Quellen verarbeitet.

Dazu können insbesondere offizielle Partnerinformationen, Herstellerinformationen und öffentliche Primärquellen gehören.

## Aktualisierung

Zeitabhängige Informationen werden mit ihrem jeweiligen Datenstand betrachtet.

Änderungen an Preisen, Konditionen, Verfügbarkeit oder Angeboten können jederzeit durch den jeweiligen Anbieter erfolgen.
