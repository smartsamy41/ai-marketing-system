# Strukturierte Daten

Free Basics verwendet strukturierte und maschinenlesbare Informationen, um Inhalte technisch eindeutig zu beschreiben.

## Technologien

Dazu gehören je nach Seitentyp:

- Schema.org
- JSON-LD
- Open Graph
- Canonical URLs
- XML Sitemap
- Knowledge-Graph-Daten
- llms.txt
- OpenAPI

Strukturierte Daten dürfen nur Aussagen enthalten, die durch den tatsächlichen Seiteninhalt und die zugrunde liegenden Daten gestützt werden.
